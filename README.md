#  AI & Machine Learning Journey

Welcome to my AI/ML learning repository! This project tracks my progress through various machine learning concepts, from foundational math to advanced neural network implementations.

##  Repository Structure

The repository is organized into three main sections for easy navigation:

###  [Notes](./Notes/)
Theoretical documentation and study materials.
*   **[Neural Networks](./Notes/Neural-Networks/)**: Activation functions, optimization (Adam, etc.), and multi-class classification
*   **[NumPy & Pandas](./Notes/NumPy-Pandas/)**: Practical guides and roadmaps for data manipulation.

### [Code](./Code/)
Practical implementations and experiments.
*   **[Implementations](./Code/Implementations/)**: Core models built from scratch (Linear Regression, Gradient Descent).
*   **[Notebooks](./Code/Notebooks/)**: Detailed Jupyter Notebooks with data analysis and model training.
*   **[Practice Exercises](./Code/Practice-Exercises/)**: Scripting exercises for NumPy, OOP, and more.

### 📁 [Assets](./Assets/)
Project resources, including visualizations and screenshots used in the documentation.

##  Tech Stack
*   **Languages**: Python
*   **Libraries**: NumPy, Pandas, TensorFlow/Keras, Matplotlib
*   **Tools**: Jupyter Notebooks, VS Code

## Learning Roadmap
Currently focusing on Deep Learning and Neural Network optimization techniques. Next steps include exploring Convolutional Neural Networks (CNNs) in more depth.
