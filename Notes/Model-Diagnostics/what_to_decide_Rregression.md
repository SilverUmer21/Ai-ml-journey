It turns out that each of these six items either ​helps fix a high variance or a high bias problem
 if your learning algorithm has high bias, ​three of these techniques will be useful. ​If your learning algorithm has high variance than a ​different three of these techniques will be useful

 # If model has high variance 
* Adding more and more training data can be helpful
* Trying smaller set of features can help as it will reduce the flexibility of your model to overfit the data
