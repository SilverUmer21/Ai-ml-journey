#  Code Implementations & Experiments

This directory contains the practical side of my AI/ML journey. It is divided into three main categories:

## 📂 Folders

### 1. [Implementations](./Implementations/)
Core machine learning models built from scratch using NumPy. These scripts focus on the underlying mathematics and logic of algorithms like Linear Regression and Gradient Descent without relying on high-level libraries.

### 2. [Notebooks](./Notebooks/)
Jupyter Notebooks containing guided labs, data visualizations, and experiments with TensorFlow/Keras. These provide a more interactive and visual way to explore concepts like Neural Networks and Optimization.

### 3. [Practice Exercises](./Practice-Exercises/)
Small scripts and challenges designed to sharpen specific skills, such as Python Object-Oriented Programming (OOP) and basic classification tasks.

## How to use
- All scripts follow a professional `snake_case` naming convention.
- Numeric prefixes (01, 02, ...) indicate the recommended order of exploration.
- Ensure you have the necessary dependencies installed (`pip install numpy pandas matplotlib tensorflow`).
